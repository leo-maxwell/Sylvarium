# Sylvarium Project Design Choices

## AI Policy
Every single line of code that is not from external libraries is typed entirely by human fingers. Apart from this guarantee, AI usage may occur.

## Project design
### Aesthetics
Every visible detail of the current publicly available version of blog website is deliberately designed by the author and reflect the definition of utmost beauty in author's mind.

## Scope and functionality
### Markdown support
Currently only plain .md is supported. Files with .mdx suffix will not work at the moment.

## Technical details
### The trailing slash
We keep all trailing slashes at the end of each page. For example, blog.leo-maxwell.com/en/
